# MatPris – مقارنة أسعار الطعام في السويد

تطبيق جاهز للإنتاج يغطي نقاط الواجهة، قاعدة البيانات، الدخول، الصلاحيات، الأمان، الاستضافة، السجلات، النسخ الاحتياطي، التواصل، وسياسة الخصوصية.

## التشغيل السريع

```bash
npm install
cp .env.example .env.local   # غيّر كلمة مرور المشرف
npm run dev
```

افتح http://localhost:3000

نسخة بدون تثبيت: افتح `MatPris.html` في المتصفح.

## الصفحات

| المسار | الوظيفة |
|--------|---------|
| `/` | بحث ومقارنة وسلة |
| `/login` | دخول المشرف |
| `/admin` | إدارة (محمية) – روابط، وارد، سجلات، نسخ احتياطي |
| `/privacy` | سياسة الخصوصية |
| `/contact` | تواصل / إيميل |

**دخول المشرف الافتراضي:** أي بريد + كلمة المرور `matpris-admin`  
(غيّرها في `.env.local` → `NEXT_PUBLIC_ADMIN_PASSWORD`)

10. **التنبيهات** – رسائل UI  
11. **النسخ الاحتياطي** – تصدير JSON  
12. **الدفع** – غير مطلوب (تطبيق مجاني)

## الاستضافة (Vercel)

1. ارفع المشروع إلى GitHub  
2. Import في [vercel.com](https://vercel.com)  
3. أضف Environment Variable: `NEXT_PUBLIC_ADMIN_PASSWORD`  
4. Deploy – HTTPS جاهز  
5. Settings → Domains لربط نطاقك

## تحديث الأسعار أسبوعيًا

```bash
# ضع الملفات في:
# data/imports/ica/2026-W48.xlsx
npm run update
```

أو اترك GitHub Action `.github/workflows/weekly-update.yml` يعمل كل اثنين.

## الأمان

- لا ترفع `.env.local` إلى Git  
- غيّر كلمة مرور المشرف قبل النشر العام  
- للإنتاج المتقدم: استبدل الجلسة المحلية بـ Supabase Auth أو NextAuth
